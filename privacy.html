개인정보처리방침

시행일: 2026년 11월 9일

1. 이 프로그램이 하는 일

겜추녀 업로더는 운영자 본인의 유튜브 채널에 영상, 썸네일, 재생목록을 올리는 개인용 프로그램입니다. YouTube Data API를 사용하며, 운영자 한 명만 사용합니다.

2. 사용하는 정보

  • 운영자가 구글 로그인으로 허락한 유튜브 채널 접근 권한(OAuth 토큰)
  • 업로드할 영상 파일, 제목, 설명, 썸네일

다른 사용자의 개인정보는 모으지 않습니다.

3. 보관과 공유

로그인 토큰은 운영자의 컴퓨터에만 저장되며, 제3자에게 팔거나 공유하지 않습니다. 구글 API로 받은 정보는 업로드 기능에만 사용합니다. 이 프로그램의 구글 API 정보 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

구글 계정의 서드파티 앱 및 서비스에서 언제든지 접근 권한을 해제할 수 있습니다.

5. 문의

유튜브 채널 겜추녀의 정보 탭으로 문의해 주세요.
